## 修复：设备管理员登录后其他页面打不开的问题
### 问题分析
- 首页从 localStorage 读取用户信息后立即渲染，不需要等待 API 验证
- 其他页面使用 `useAuth` hook，当 `checkAuth` 验证失败时 `user` 状态被清除
- 导致页面跳转到登录页

### 修复内容
1. **改进 `useAuth` hook** (`frontend/src/hooks/useAuth.tsx`)
   - `checkAuth` 现在会优先使用本地存储的用户数据
   - 只有当本地存储没有用户数据时才会调用 `/api/users/me`
   - 网络错误时保留本地存储数据，允许离线访问
   - 添加 `authChecked` 状态标识验证是否完成

2. **修复 TypeScript 错误**
   - 5个页面组件缺少 `isSuperAdmin` 变量声明
   - 已在 DeviceList、ToolList、PartList、RepairList、MaintenancePlan 中添加

## 息屏后手机端无法访问问题修复（2026-05-16）
### 问题分析
- 电脑息屏后，后端服务可能无响应
- 会话有效期过短（8小时）
- 前端缺少网络状态检测和自动重连机制

### 修复内容
1. **后端优化** (`backend/server.js`)
   - 将会话有效期从 8 小时延长到 24 小时
   - 添加 `secure: false` 允许 HTTP 连接

2. **新增心跳接口** (`backend/routes/users.js`)
   - 添加 `/api/users/ping` 接口用于心跳检测和会话续期

3. **前端优化** (`frontend/src/hooks/useAuth.tsx`)
   - 添加心跳检测机制，每 5 分钟检测一次连接状态
   - 添加 `isConnected` 状态标识网络连接
   - 断线超过 30 分钟自动清除登录状态
   - 登录成功后自动启动心跳

4. **新增网络状态提示** (`frontend/src/App.tsx`)
   - 添加 `NetworkStatusBanner` 组件
   - 网络断开时显示红色提示条
   - 提供"重试"按钮
