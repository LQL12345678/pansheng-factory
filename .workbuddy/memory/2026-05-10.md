# 2026-05-14 工作日志

## 用户管理和三级权限控制系统完成

### 新增功能

#### 三级角色定义
- **超级管理员 (super_admin)**：所有权限 + 用户管理（新增/编辑/删除/重置密码）
- **设备管理员 (admin)**：所有业务权限（增删改查），没有用户管理权限
- **普通用户 (user)**：只能查看数据 + 新建报修 + 零部件领用，没有编辑/删除/入库权限

#### 权限矩阵
| 功能 | 超级管理员 | 设备管理员 | 普通用户 |
|------|----------|----------|---------|
| 用户管理 | ✓ | ✗ | ✗ |
| 设备增删改 | ✓ | ✓ | ✗ |
| 备件入库 | ✓ | ✓ | ✗ |
| 备件领用 | ✓ | ✓ | ✓ |
| 工单处理 | ✓ | ✓ | ✗ |
| 新建报修 | ✓ | ✓ | ✓ |
| 查看数据 | ✓ | ✓ | ✓ |

### 实现内容

#### 后端
- **数据库**：修改 `users` 表，`role` 字段从 `admin/user` 升级为 `super_admin/admin/user`
- **认证接口**：`/api/auth/login` 返回用户角色名称
- **权限接口**：`/api/auth/permissions` 返回用户权限配置
- **中间件**：
  - `requireAuth` - 验证登录
  - `requireSuperAdmin` - 超级管理员权限
  - `requireAdmin` - 设备管理员及以上权限
  - `requireRepairStaff` - 工单处理权限
  - `requireStockIn` - 备件入库权限

#### 前端
- **登录页面**：`LoginPage.tsx` + `LoginPage.css`
- **用户管理页面**：`UserManagement.tsx` + `UserManagement.css`
- **权限控制 Hook**：`hooks/useAuth.tsx`
  - `useAuth()` - 获取用户信息和权限
  - `useIsSuperAdmin()` - 是否超级管理员
  - `useIsAdmin()` - 是否设备管理员及以上
  - `usePermission(permission)` - 检查某项权限
- **App.tsx 更新**：
  - 路由守卫（未登录跳转登录页）
  - 菜单权限控制（用户管理仅超级管理员可见）
  - 顶部栏显示角色和用户名
  - 登出按钮
- **各页面权限控制**：
  - `DeviceList.tsx` - 新增/编辑/删除/报废按钮
  - `PartList.tsx` - 新增/编辑/删除/入库按钮
  - `RepairList.tsx` - 工单处理/编辑/删除按钮
