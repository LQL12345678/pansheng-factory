========================================
  攀升设备管理系统 - 图标设置说明
========================================

一、图标文件
------------
icon.png - 高科技风格应用图标
  - 深蓝色背景 + 亮蓝色渐变
  - 齿轮 + 电路板纹路设计
  - 底部有 PS-EMS 标识


二、设置桌面图标
----------------

首次设置（只运行一次）：
  1. 右键 setup-icon.ps1
  2. 选择 "使用 PowerShell 运行"
  3. 完成桌面图标 + 开机自启设置

完成后桌面上会出现：
  "攀升设备管理系统" 图标（带高科技图标）


三、取消设置
------------

右键 remove-icon.ps1 -> 使用 PowerShell 运行

这会删除：
  - 桌面快捷方式
  - 开机启动项


四、开机自动启动
----------------

设置后，每次开机电脑会自动：
  1. 启动后端服务 (端口 3001)
  2. 启动前端服务 (端口 5173)
  3. 打开浏览器进入登录页面

登录信息：
  地址: http://localhost:5173
  用户名: admin
  密码:   admin123


五、其他启动方式
----------------

如果图标方式有问题，也可以：
  1. 双击 start-simple.bat 启动
  2. 双击 stop-simple.bat 停止
