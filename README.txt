========================================
  攀升工厂设备管理系统 - 使用说明
========================================

一、快速使用
------------

首次设置（只运行一次）：
  1. 右键 setup-desktop.ps1
  2. 选择 "使用 PowerShell 运行"
  3. 完成桌面图标和开机自启设置

日常使用：
  1. 双击桌面 "攀升设备管理系统" 图标
  2. 自动启动前后端服务
  3. 浏览器自动打开登录页面


二、脚本说明
------------

启动相关：
  start-simple.bat   - 启动脚本 (双击运行)
  stop-simple.bat    - 停止脚本

设置相关：
  setup-desktop.ps1  - 创建桌面图标 + 开机自启
  remove-desktop.ps1 - 移除桌面图标 + 开机自启

PowerShell 版本：
  start.ps1          - PowerShell 启动脚本
  stop.ps1           - PowerShell 停止脚本


三、开机自动启动
----------------

设置方法：
  右键 setup-desktop.ps1 -> 使用 PowerShell 运行

取消开机自启：
  右键 remove-desktop.ps1 -> 使用 PowerShell 运行


四、登录信息
------------
  地址: http://localhost:5173
  用户名: admin
  密码:   admin123


五、故障排除
------------

Q: 双击 .bat 文件没反应？
A: 右键 -> 使用 PowerShell 运行

Q: 端口被占用？
A: 先运行 stop-simple.bat 或 stop.ps1

Q: 想查看运行状态？
A: 打开任务管理器 -> 进程 -> 找 node.exe
